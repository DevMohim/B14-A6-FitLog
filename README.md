## PROJECT NAME : **FitLog**

## **Description**
FitLog is a workout planning website where users can create a workout plan for the day and save workouts for later. It includes a sticky navigation bar, a banner with a call-to-action button, and a workout library. Users can also view individual workout details and visit the My Plan page to see their planned and saved workouts.

## **Technologies Used**
1. Next.js
2. React
3. JavaScript
4. HTML
5. Tailwind CSS
6. DaisyUI
7. React Icons

## **Key Features**
1. Add workouts to today’s plan
2. Save workouts for later
3. Sort workouts by duration, calories burned, or rating
4. Delete individual workouts
5. Mark workouts as done
